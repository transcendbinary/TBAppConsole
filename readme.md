# TB CLI APP - .NET 10 MULTIPLATFORM CONSOLE APPLICATION

## How to Install

### linux

- Ensure you have .NET and git installed and set up
  - install .NET using `sudo pacman -S dotnet` or `sudo apt install dotnet`
  - install git using `sudo pacman -S git` or `sudo apt install git`
  - sign into and set up git (see setup steps [here](https://docs.github.com/en/get-started/git-basics/set-up-git))
- clone the repo with `git clone https://github.com/transcendbinary/TBAppConsole`
- navigate to the repo (`cd TBAppConsole`)
- run `dotnet build` to build the app
- locate the built binary
- run it with ./TBAppConsole

## windows

- download and sign into [visual studio community](https://visualstudio.microsoft.com/)
- sign into github in VS
- clone and open the repo in VS (https://github.com/transcendbinary/TBAppConsole)
- navigate to Build > Build Solution
- Locate the built binary
- double click to run

OR

- install and set up git
- install the [.NET SDK] (https://dotnet.microsoft.com/en-us/)
- clone the repo with `git clone https://github.com/transcendbinary/TBAppConsole`
- navigate to the repo (`cd TBAppConsole`)
- run `dotnet build` to build the app
- locate the built binary
- run it with TBAppConsole.exe
